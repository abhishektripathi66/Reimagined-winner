Dhan API Setup (Free):
  1. Login at web.dhan.co → My Profile → Dhan HQ → API
  2. Enable API access (free for all Dhan users)
  3. Generate your access_token — valid for 24 hours only, so make a fresh one each day
  4. Your client_id is your Dhan User ID shown in the app
  5. Put both values in DHAN_CLIENT_ID and DHAN_ACCESS_TOKEN in the adjacent .env, then restart the backend
✅ Dhan API is completely free — no subscription charges. Supports CNC, Intraday, F&O, Bracket & Cover orders.
